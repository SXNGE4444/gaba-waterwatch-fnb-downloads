How to install

1

Open this page using Chrome on your Android phone. Tap Download APK.

2

Open Files → Downloads or your browser's Downloads menu. Tap GABA-WaterWatch-FNB-v0.9.5-JUDGES.apk.

3

If Android blocks this download or installation, follow the phone's prompt to allow Install unknown apps for the app you trust (such as Chrome or Files). You can turn this permission off again after installation. Do not disable Play Protect.
